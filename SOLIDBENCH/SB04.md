# SOLIDBENCH 04

`sb-04.html` uses OpenSCAD as the durable geometry authority.

## Run

Install OpenSCAD, then run:

```sh
cd /Users/gaia/GUNNAR/gunnars-depot.html/SOLIDBENCH
python3 solidbench_server.py
```

Open the exact URL printed by the server.

## Operational path

1. The Builder returns executable OpenSCAD source.
2. The code tab exposes that source directly.
3. Build Version posts the source to the local server.
4. The server writes `<name>_NNN.scad` without overwriting prior work.
5. OpenSCAD renders `<name>_NNN.png` and exports `<name>_NNN.stl`.
6. The server stores compiler output and warnings in `<name>_NNN.json`.
7. SOLIDBENCH loads that exact STL into Three.js.
8. View, section, probe, wall, and overhang tools inspect the returned mesh.
9. Export downloads the authoritative OpenSCAD STL.

Artifacts live in `SOLIDBENCH/artifacts/` and are excluded from Git.
