How this bench works

Three ways to build, one truth. Drag parts, ask the Builder, or write CSG in the code tab — all feed the same manifold-3d kernel, which guarantees a watertight, printable solid.

Parts are CSG. Each part is a primitive with a transform; the scene compiles to a script the kernel runs. Mark a part as a cut to subtract it (holes, slots).

The report is real. Watertight is kernel-certified; overhang is exact; min-wall is a three-axis estimate. Export unlocks only when the print checks pass.

Honest about limits. The kernel, the Builder, and multiplayer each need network access; if any is blocked you'll see it say so, never a fake result.
